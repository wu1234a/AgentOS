# 前端 Worker / Pipeline 与浏览器生产化

状态：Completed
来源：已批准后续建议

## 前端

- `/workers`：Worker 统计、列表、运行任务、心跳、启停。
- `/pipelines`：最近任务列表 + 阶段时间线抽屉。
- 路由与侧边栏入口。
- 前端 lint/build 通过。

## 浏览器适配器

- 进程内最多 2 个并发浏览器会话（`SemaphoreSlim`）。
- 截图目录按 `ScreenshotRetentionHours`（默认 24）清理旧文件。
- 取消仍会关闭浏览器；白名单路由拦截保留。
